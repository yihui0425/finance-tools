## 工具列表

### 💰 營運資金計算器（Working Capital Simulator）

輸入財務參數後即時計算可支撐年營收與現金轉換週期（CCC）。

**輸入欄位：**
| 欄位 | 說明 |
|------|------|
| 現金總額 | 公司帳上現金 |
| 質押定存 | 不可動用部分自動扣除 |
| 預收貨款 | 抵減營運資金需求 |
| 毛利率 | % |
| AR 天數（DSO） | 應收帳款天數 |
| 存貨天數（DIO） | 存貨週轉天數 |
| AP 天數（DPO） | 應付帳款天數 |

**計算結果：**
- 可動用現金淨額（現金 − 質押 + 預收）
- CCC 現金轉換週期（DSO + DIO − DPO）
- 可支撐年營收 / 月均營收
- AR / 存貨 / AP 各項資金佔用
- 改善建議（單一變數調整效益）
- 存貨天數情境分析表

### 📋 IFRS 15/9 分期付款試算工具

依 IFRS 15.60–65 重大融資成分規範，自動產生分期付款銷貨的完整合規底稿。

**功能包含：**
- 報價成本明細輸入（含逐期成本）
- 重大融資成分判斷（IFRS 15.60–65）
- 有效利率法攤銷表
- 逐期損益表（收益 / 利息收入 / 成本 / 毛利）
- 會計分錄產生
- Excel 匯出
